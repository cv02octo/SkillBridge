Stack

Learn the LIFO principle, stack operations, implementation in Java and important Stack concepts.

What is a Stack?

A Stack is a linear data structure that follows the LIFO principle.

LIFO means Last In, First Out.

TOP ↓
30
20
10

The element 30 was inserted last, so it will be removed first.

Real Life Example

Think about a stack of plates.

The last plate placed on the top is the first plate that we remove.

Plate Stack → LIFO

Last plate added → First plate removed

Stack Operations

Push

Adds an element to the top of the stack.

Pop

Removes the top element from the stack.

Peek

Returns the top element without removing it.

Stack in Java

Java provides a built-in Stack class. 

import java.util.Stack;

Stack<Integer> stack = new Stack<>();

stack.push(10);
stack.push(20);
stack.push(30);

System.out.println(stack.peek());

stack.pop();

System.out.println(stack.peek());

Output:
30
20

Important Points

1. LIFO

Last In, First Out.

2. Top

Insertion and deletion happen at the top.

3. Applications

Used in recursion, undo operations, browser history and expression evaluation.
