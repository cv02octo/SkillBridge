Linked List

Learn nodes, traversal, insertion, deletion and important Linked List concepts step by step.

What is a Linked List?

A Linked List is a linear data structure where elements are stored in separate objects called nodes.

Each node contains two main things: data and a reference to the next node.

Data: 10
→
Data: 20
→
Data: 30
→
NULL

What is a Node?

A node is the basic building block of a Linked List. It stores data and the address/reference of the next node.

Node Structure

class Node {

    int data;
    Node next;

}

Linked List in Java

We can create our own Node class and connect nodes using the next reference. 

class Node {

    int data;
    Node next;

    Node(int data) {
        this.data = data;
        this.next = null;
    }
}

Node first = new Node(10);
Node second = new Node(20);

first.next = second;

Linked List Traversal

Traversal means visiting every node of the Linked List one by one. 

Node temp = first;

while(temp != null) {

    System.out.println(temp.data);

    temp = temp.next;
}

Output:
10
20

Insertion

Insertion means adding a new node to the Linked List. A node can be inserted at the beginning, middle or end.

Example

Before: 10 → 20 → 30

Insert 15: 10 → 15 → 20 → 30

Deletion

Deletion means removing a node from the Linked List.

Example

Before: 10 → 20 → 30

Delete 20: 10 → 30

Important Points

1. Node

Stores data and reference to the next node.

2. Head

The first node of a Linked List is called Head.

3. NULL

The last node points to NULL.

4. Dynamic Size

Linked Lists can grow and shrink dynamically.
