Queue

Learn Queue data structure and understand FIFO with simple examples.

What is a Queue?

A Queue is a linear data structure in which the element inserted first is removed first.

Queue follows the FIFO principle: First In, First Out.

10
→
20
→
30
→
40

Real-Life Example

Imagine people standing in a line at a ticket counter. The person who comes first gets the ticket first.

This is exactly how a Queue works.

Queue Operations

Enqueue

Adds an element to the rear of the queue.

Dequeue

Removes an element from the front.

Peek

Returns the front element without removing it.

Queue in Java

import java.util.*;

Queue<Integer> q = new LinkedList<>();

q.add(10);
q.add(20);
q.add(30);

System.out.println(q);

q.remove();

System.out.println(q);

Important Points

FIFO

First In, First Out.

Front

Element that will be removed first.

Rear

Position where new elements are added.
