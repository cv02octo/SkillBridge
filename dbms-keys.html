🔑 DBMS Keys

Learn how keys identify and connect records in a database

📘 What is a Key?

A key is an attribute or a combination of attributes used to identify records in a database.

Keys help maintain uniqueness and establish relationships between different tables.

💡 Simple Example:

In a Student table, Roll Number can uniquely identify each student. Therefore, Roll Number can be used as a key.

1️⃣ Primary Key

A Primary Key uniquely identifies every record in a table.

It cannot contain duplicate or NULL values.

Example:

Student(Roll_No, Name, Course)

Roll_No can be the Primary Key because every student has a unique Roll Number.

2️⃣ Foreign Key

A Foreign Key is used to connect two tables.

It usually refers to the Primary Key of another table.

Example:

Student table has Course_ID as a Foreign Key. It can refer to Course_ID in the Course table.

3️⃣ Candidate Key

A Candidate Key is an attribute or combination of attributes that can uniquely identify a record.

One of the candidate keys is selected as the Primary Key.

4️⃣ Super Key

A Super Key is any set of attributes that can uniquely identify a record.

A Super Key may contain extra attributes.

5️⃣ Composite Key

A Composite Key is made using two or more attributes together to uniquely identify a record.

Example:

Student_ID + Course_ID can together uniquely identify a student's course enrollment.

📊 Key Comparison

Key Main Purpose
Primary Key Uniquely identifies each record
Foreign Key Connects two tables
Candidate Key Possible choice for Primary Key
Super Key Uniquely identifies a record
Composite Key Uses multiple attributes together

📝 Quick Revision

  • Primary Key uniquely identifies each record.
  • Primary Key cannot contain duplicate values.
  • Primary Key cannot contain NULL values.
  • Foreign Key connects two tables.
  • Candidate Keys are possible choices for Primary Key.
  • Super Key can contain extra attributes.
  • Composite Key contains two or more attributes.
