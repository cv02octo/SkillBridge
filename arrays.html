Arrays

Learn the fundamentals of arrays and understand how they are stored, accessed and processed.

What is an Array?

An array is a data structure used to store multiple values of the same type in a single variable.

Each element of an array has an index. In most programming languages, array indexing starts from 0.

10
20
30
40
50
Index:   0    1    2    3    4

Array in Java

We can create an integer array in Java using the following syntax: 

int[] arr = {10, 20, 30, 40, 50};

System.out.println(arr[0]);
System.out.println(arr[2]);

Output: 

10
30

Array Traversal

Traversal means visiting every element of the array one by one. 

int[] arr = {10, 20, 30, 40, 50};

for(int i = 0; i < arr.length; i++){

    System.out.println(arr[i]);

}

Important Points

Index

Array indexing starts from 0.
Length

Use arr.length to get array size.
Access

Elements can be accessed using their index.
Traversal

A loop can be used to visit all elements.
