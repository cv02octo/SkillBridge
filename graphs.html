1. What is a Graph?

A Graph is a non-linear data structure consisting of vertices (nodes) and edges.

Example

Suppose we have four cities: A, B, C and D.

If A is connected to B, then we can represent this connection using an edge.

Important Terms

  • Vertex: A node in the graph.
  • Edge: Connection between two vertices.
  • Directed Graph: Edges have a direction.
  • Undirected Graph: Edges have no direction.
  • Weighted Graph: Edges have a value/cost.
  • Unweighted Graph: Edges do not have a weight.

2. Graph Representation

Graphs are mainly represented using:

  • Adjacency Matrix
  • Adjacency List

Adjacency Matrix

An adjacency matrix uses a 2D array to represent connections between vertices. 

int[][] graph = {
    {0, 1, 0},
    {1, 0, 1},
    {0, 1, 0}
};

Adjacency List

An adjacency list stores the connected vertices for every vertex. 

ArrayList<Integer>[] graph =
    new ArrayList[5];

graph[0].add(1);
graph[1].add(0);

3. BFS - Breadth First Search

BFS means Breadth First Search.

BFS visits nodes level by level. It uses a Queue.

Simple Example

If the graph is: 

        0
       / \
      1   2
     / \
    3   4

BFS traversal: 

0 → 1 → 2 → 3 → 4

Java Example

import java.util.*;

class BFS {

    static void bfs(
        ArrayList<Integer>[] graph,
        int start
    ) {

        boolean[] visited =
            new boolean[graph.length];

        Queue<Integer> queue =
            new LinkedList<>();

        queue.add(start);
        visited[start] = true;

        while (!queue.isEmpty()) {

            int node = queue.remove();

            System.out.print(node + " ");

            for (int next : graph[node]) {

                if (!visited[next]) {

                    visited[next] = true;
                    queue.add(next);
                }
            }
        }
    }
}

4. DFS - Depth First Search

DFS means Depth First Search.

DFS goes as deep as possible before coming back. It can be implemented using recursion or a stack.

Example

        0
       / \
      1   2
     / \
    3   4

One possible DFS traversal: 

0 → 1 → 3 → 4 → 2

Java Example

import java.util.*;

class DFS {

    static void dfs(
        ArrayList<Integer>[] graph,
        int node,
        boolean[] visited
    ) {

        visited[node] = true;

        System.out.print(node + " ");

        for (int next : graph[node]) {

            if (!visited[next]) {

                dfs(graph, next, visited);
            }
        }
    }
}
