🔍 Searching Algorithms

📚 What is Searching?

Searching means finding a particular element inside an array or collection.

1️⃣ Linear Search

Linear Search checks every element one by one until the required element is found.

Java Example

int[] arr = {10, 20, 30, 40, 50};
int target = 30;

for(int i = 0; i < arr.length; i++){

    if(arr[i] == target){

        System.out.println("Found at index " + i);
        break;

    }

}

2️⃣ Binary Search

Binary Search works on a sorted array. It repeatedly divides the search range into two halves.

Java Example

int[] arr = {10, 20, 30, 40, 50};

int target = 40;

int left = 0;
int right = arr.length - 1;

while(left <= right){

    int mid = (left + right) / 2;

    if(arr[mid] == target){

        System.out.println("Found");
        break;

    }
    else if(arr[mid] < target){

        left = mid + 1;

    }
    else{

        right = mid - 1;

    }

}

💡 Remember

Linear Search → works on any array.
Binary Search → array must be sorted.

📊 Sorting Algorithms

📚 What is Sorting?

Sorting means arranging elements in ascending or descending order.

1️⃣ Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

Java Example

int[] arr = {5, 2, 8, 1};

for(int i = 0; i < arr.length - 1; i++){

    for(int j = 0; j < arr.length - i - 1; j++){

        if(arr[j] > arr[j + 1]){

            int temp = arr[j];

            arr[j] = arr[j + 1];

            arr[j + 1] = temp;

        }

    }

}

2️⃣ Selection Sort

Selection Sort repeatedly finds the smallest element and places it at the correct position.

3️⃣ Insertion Sort

Insertion Sort builds the sorted array one element at a time.

📝 Practice Question
