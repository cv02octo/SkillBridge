Strings

Learn how strings work in Java, how to access characters, traverse strings and perform common string operations.

What is a String?

A String is a sequence of characters. In Java, String is a class used to store and work with text.

Example

"HELLO" contains 5 characters: H, E, L, L, O

String in Java

We can create a String using double quotes. 

String name = "SkillBridge";

System.out.println(name);

Output: SkillBridge

Access Characters

We can use charAt() to access a particular character from a String. 

String str = "JAVA";

System.out.println(str.charAt(0));
System.out.println(str.charAt(2));

Output:
J
V

String Traversal

We can use a loop to visit every character of a String. 

String str = "JAVA";

for(int i = 0; i < str.length(); i++) {
    System.out.println(str.charAt(i));
}

Output:
J
A
V
A

Important Points

1. length()

Returns the number of characters in a String.

2. charAt()

Returns the character at a particular index.

3. toUpperCase()

Converts the String into uppercase.

4. toLowerCase()

Converts the String into lowercase.
