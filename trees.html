Trees

Learn the basics of Tree data structure with simple examples.

What is a Tree?

A Tree is a non-linear data structure that represents data in a hierarchical form.

A Tree consists of nodes connected by edges.

Important Tree Terms

Root

The topmost node of a tree.

Node

An element that stores data.

Edge

Connection between two nodes.

Leaf

A node that has no children.

Binary Tree

A Binary Tree is a tree in which each node can have at most two children.

These children are called the left child and right child.

Tree in Java

class Node {

    int data;

    Node left;
    Node right;

    Node(int data) {

        this.data = data;
        left = null;
        right = null;
    }
}

Important Points

Root

First or topmost node.

Child

Node connected below another node.

Parent

Node that has one or more children.

Leaf

Node without children.
